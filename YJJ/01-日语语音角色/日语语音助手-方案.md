# 日语语音角色 · 完整搭建方案

> 目标：一个在你自己电脑上跑的对话角色，用日语回答、用你提供的日语音色说话。
> 硬件：RTX 4060 Laptop（8G 显存）/ 16G 内存 / Windows 11
> 预算：**0 元**（除 DeepSeek API 每天几毛钱）

---

## 一、这套东西由三块拼成

```
  你说话                          它回答
    │                               ▲
    ▼                               │
┌─────────┐   文字   ┌──────────┐  文字   ┌──────────┐   音频   ┌────────┐
│ whisper │ ───────▶ │ DeepSeek │ ──────▶ │  日语TTS  │ ──────▶ │  音箱   │
│  (耳朵)  │          │  (大脑)  │         │  (嘴巴)   │         │        │
└─────────┘          └──────────┘         └──────────┘         └────────┘
                            ▲                   ▲
                            │                   │
                      也可以直接打字        你训练出的音色
```

- **耳朵**：faster-whisper，把你说的话转成文字（不想说话可以跳过，直接打字）
- **大脑**：DeepSeek API，决定说什么、用日语说、用什么语体
- **嘴巴**：GPT-SoVITS，用你的日语素材训练出来的音色，把文字念出来

**关键**：音色只在「嘴巴」这一块。训练一次，之后一直用。

---

## 二、硬件怎么分配（8G 显存的细账）

| 项目 | 显存 | 内存 |
|---|---|---|
| GPT-SoVITS 推理（常驻） | 2–3 G | 1–2 G |
| faster-whisper large-v3-turbo（int8） | ~1 G | ~1 G |
| DeepSeek | 0 | 0 |
| **合计** | **3–4 G** | **3 G 左右** |

剩 4G 显存给系统和其他程序，够用，但没有挥霍的余地。

**所以：**
- 浏览器标签跑起来之前关一关，16G 内存最先撑不住
- 训练的时候别开别的大程序
- 笔记本垫高，风扇会拉满

**ASR 选型说明**：日语别用 `small`，准确率不够，专有名词会错得离谱。用 `large-v3-turbo` 的 int8 量化，体积和 `medium` 差不多，日语准得多，速度还快。这是这款模型最值的地方。

## 四、六个步骤

### 第 0 步 · 环境（30 分钟，主要是下载）

1. 下载 GPT-SoVITS 整合包（Windows 一键包，含运行环境）
2. 解压到 **纯英文路径**，比如 `D:\GPTSoVITS\`
   - 路径里不能有中文、不能有空格。这条不是建议，是硬要求。
3. 双击 `go-webui.bat`，能打开网页界面就说明环境通了

### 第 1 步 · 素材处理（自动 1 小时 + 你校对 30 分钟）

这一步决定音色上限，比训练参数重要十倍。

1. **统一格式**：全部转成 44100Hz / 单声道 / wav
2. **切分**：用 VAD 自动切，每段 3–10 秒
   - 太短：模型学不到语调
   - 太长：音色会漂
3. **自动打日文字幕**：用 faster-whisper large-v3-turbo 转写
4. **人工校对**：这一步只能你来
   - 人名、地名、专有名词最容易错
   - 数字：`3` 可能被写成 `さん`，要确认
   - 语气词、拟声词：「えっと」「あの」这些是音色的灵魂，别删

产物是一份标注清单，长这样：

```
D:\素材\0001.wav|speaker|JA|今日はいい天気ですね。
D:\素材\0002.wav|speaker|JA|ちょっと待ってください。
```

> 那些教程让你一句一句手打字幕，纯属拿你的时间不当钱。自动跑，你只负责改错。

### 第 2 步 · 训练（1–2 小时，跑起来就不用管）

1. 在 WebUI 里选 **v2 系列**（日语支持最稳的一版）
2. 填入标注清单路径，点「一键格式化」
3. 训练 GPT 模块 —— 8 到 20 轮
4. 训练 SoVITS 模块 —— 8 到 20 轮
5. 挑一个效果最好的存档，**固化成模型**

产出两个文件，之后一直用这两个。

**4060 8G 上的现实**：batch size 只能开小，训练比台式卡慢，一到两小时。期间显存会吃满，别干别的。

### 第 3 步 · 起服务（我要做的）

不用 WebUI 界面聊天，那玩意儿是给调参用的。改成后台服务：

- 常驻一个进程，走本地接口
- **空闲 20 分钟自动退出**，把显存还给你
- 下次用时点一下，等 20 秒加载

为什么不能「每次用的时候现开」：PyTorch 初始化 CUDA 加加载模型要 15–40 秒，每句话前等半分钟，这东西就废了。常驻是唯一合理的选择。

### 第 4 步 · 串起来（我要做的）

主循环：

```
录音 → 检测到你说完 → 转文字 → 发给 DeepSeek → 
按标点切句 → 逐句合成 → 边合成边播
```

**必须流式、必须按句切。** 等整段生成完再播，一句话让你干等三秒。切句的时候要认日语的 `、` 和 `。`，不能用中文那套。

**打断功能**：它说话的时候你开口，得立刻停下。这个不做，用两天就烦。

### 第 5 步 · 日语专有的三个处理

1. **语体要写死**。`です・ます` 的敬语、`だ・である` 的常体、`タメ口` 的随意口吻 —— 不指定，它自己挑，同一个角色的味道就散了。
2. **数字要预处理**。`3`、`1000`、`2026年` 直接喂给 TTS 可能念错。转成日语读法再喂。
3. **别夹中文**。DeepSeek 写日语不难，但不约束它，它偶尔会给你来一句中文旁白。提示词里要明说，输出后再检查一遍。

### 第 6 步 · 打磨（可选，看你还想不想折腾）

- **情感**：GPT-SoVITS 支持用参考音频带情绪。准备几段不同情绪的素材（开心 / 平静 / 生气），按情境切换
- **语速**：有 `speed` 参数，日语默认稍慢一点更自然
- **长句漂移**：一句超过 20 个字，音色就开始走样。切句的时候顺手卡住长度

# 附录 · 素材验收标准

## 总纲一句话

模型学的是「这个人怎么发声」。素材里**除了这个人的嗓子之外的一切**——噪声、混响、第二个人、伴奏、手机压缩的金属声——都会被一起学进去。之后你听到的所有怪味，都是当初放进去的。

所以标准只有一条：**素材里除了这个人的嗓音，别的一概不要。**

## 量化门槛

| 项目 | 及格 | 良好 | 优秀 |
|---|---|---|---|
| 信噪比 | 20 dB | 30 dB | 40 dB+ |
| 总时长 | 3 分钟 | 10 分钟 | 20–30 分钟 |
| 采样率 | 22.05 kHz | 44.1 kHz | 48 kHz 无损 |
| 单段长度 | 3–10 秒 | 4–8 秒 | 5–8 秒 |
| 语气覆盖 | 1 种 | 3 种 | 5 种以上 |
| 录音设备 | 手机 | 手机（安静房间） | USB 麦 / 声卡 |

## 红牌（见到就扔，别心疼）

| 现象 | 为什么致命 |
|---|---|
| 有 BGM、音效 | 模型会把人声和伴奏混成一个音色 |
| 有第二个人（连「嗯」「对」的附和都算） | 音色直接被污染 |
| 有空房间 / 浴室的回声 | 混响会被学成「音色的一部分」，之后永远带空间感 |
| 录的时候外放 | 另一路声音串进来，等于两个音源 |
| 直播录屏（弹幕音效、连麦、观众笑声） | 全是杂音，且采样率常常被压过 |
| 电话音质（8 kHz 窄带） | 高频全没了，音色直接塌一半 |
| 波形削波（录爆了） | 破音是不可逆的，模型会学成嘶哑 |
| 变速 / 变调处理过的 | 音高被改了，学出来的不是本人 |
| 强 AI 降噪的残留 | 那种「水下感」「金属声」比原始噪声更伤音色 |

## 黄牌（能用，但要挑着用）

| 现象 | 处理方式 |
|---|---|
| 空调 / 风扇底噪 | 能忍，但必须同一种噪声贯穿全片，否则前后音色不一致 |
| 咳嗽、清嗓、翻页 | 剪掉 |
| 笑声 | 留一两段就够，别当主力素材 |
| 语速忽快忽慢 | 能用，反而增加覆盖度 |
| 手机录的素材 | 能用，但**不要和麦克风素材混在一起** |

## 优秀素材长什么样

1. **安静房间里直接对着麦说话**，静音段听不到「沙」或「嗡」
2. 单人，无第二人、无观众反应
3. **20–30 分钟**，切好后每段 5–8 秒，切在自然停顿处
4. 覆盖至少三种语气：平静叙述、疑问、带点情绪（高兴 / 轻微不满）
5. 有自然的呼吸声和停顿——**这是加分项，不是缺陷**
6. 44.1 kHz 以上，无损或 192 kbps 以上的 mp3

## 一个反直觉的点

不是越干净越好。专业棚录、强降噪处理过的素材，模型学不到呼吸和环境感，出来像播报机器人。**适度的自然气息是加分项。** 你要的是「这个人」，不是「播音员」。

## 日语专属的四个注意

1. **日语只有 5 个元音，口型变化小**，模型能提取的特征比中文少。所以更需要不同音高的素材，否则音色单薄。
2. **高低音调（アクセント）是日语的骨架**。全是平调朗读的素材，念出来就是一板一眼的机器味。要有人说话时自然的起伏。
3. **敬语和常体两种语体都要有**。只有常体素材，念「です・ます」时会别扭。
4. **方言会跟着学进去**。素材里有明显关西腔，模型就带关西腔。要还是不要，你自己定。

## 三分钟自检（不用任何专业工具）

1. **戴耳机，把音量调到最大，听素材的静音段。** 听到「沙」或「嗡」就是底噪。
2. **在录音的房间拍一下手。** 听到拖尾的回声，说明有混响，这批素材废一半。
3. **闭上眼听一分钟。** 能不能想象这个人站在你面前说话？能，就是合格素材。
4. **看波形。** 用 Audacity 拖进去，波形顶部被削成平线 = 削波，那段扔掉。

## 处理顺序（按效果和成本的比值排）

1. **删掉不合格片段** ← 收益最大，别的都排在它后面
2. 统一采样率、转单声道、统一响度
3. 按停顿切分，3–10 秒
4. 轻降噪（只做必要的空域降噪，**不要上强 AI 降噪**）
5. 校对日语字幕

> 这五步里，第 1 步能救你后面所有的麻烦。宁可只剩 8 分钟好素材，也不要 30 分钟里掺着 BGM。
