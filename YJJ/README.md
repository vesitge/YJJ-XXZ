## YJJ 目录结构

```
YJJ/
├── 01-日语语音角色/   GPT-SoVITS + 火山 TTS 的本地日语对话页（服务端、页面、切分脚本、启动器）
├── 02-ComfyUI生图/    凉（原创角色）的 SDXL LoRA 出图环境：脚本、工作流、中文转 tag 节点、云上训练包
└── 03-笔记/           踩坑记录、项目树
```

**说明**：模型权重（.safetensors）、ComfyUI 本体、venv、音频切片、图片素材都不入库——
体积大且能从教程复现。需要时按 `02-ComfyUI生图/云上训练包/` 里的教程重新下。

**密钥**：仓库里所有 key 一律清空。`config.example.json` 是模板，
`凉-中文出图.json` 的 api_key 需要自己填。
## 什么不入库（约定）

| 类别 | 原因 |
|---|---|
| ComfyUI 本体、venv、`models/` | 换成机器/换个日子就能重装，几十 GB 没有版本意义 |
| 模型权重 `.safetensors` | 体积大、可再生（训练集 + 脚本 + 教程都在仓库里） |
| 音频原素材与切片 | 版权作品，不再分发 |
| `output/` 出图 | 体积大，按需现生成 |
| `bin/` 第三方程序（ffmpeg 等） | 第三方二进制，各自官网下 |

**要提交时**：代码、工作流、节点、打标数据、文档、教程 —— 这些才是仓库的意义。
