# 租机器训 V2 · 保姆级教程

照着一步步做，不用理解为什么。

**预计**：40 分钟到 1 小时　**花费**：3–5 元

---

## 0. 你要完成的事

把本地跑不动的 **1024 分辨率** 训练，放到租来的 4090 上跑完，拿一个新的 LoRA 回来。

本地 8 G 显存跑 1024 会崩，16 G 内存训练会卡死——这两件事云上都没有。

---

## 1. 本机先准备（现在就能做）

`生图环境\云上训练包\` 里有四个文件：

| 文件 | 用途 |
|---|---|
| `dataset.zip` | 训练集，22 张图 + 22 条 caption，13.3 MB |
| `setup.sh` | 云上装环境用 |
| `train.sh` | 云上开训用 |
| `云上说明.txt` | 贴在云端看的速查卡 |

**要上传的只有 `dataset.zip`、`setup.sh`、`train.sh` 三个。** 前两个脚本是纯文本，几 KB。

---

## 2. 租机器

### 2.1 注册

打开 <https://www.autodl.com/>，手机号注册，实名认证。

充值 **10 元**（一小时 4090 约 2 元，10 元够用五次）。

> 为什么选 AutoDL：按秒计费、自带 PyTorch 镜像、有 GitHub 学术加速。换别的平台也行，见最后一节。

### 2.2 选机器

1. 首页点「**算力市场**」
2. 左侧筛选：**RTX 4090**（24 GB 显存）
3. 地区随便，选「**有货**」的
4. 计费方式选「**按量计费**」（不要选「包日」）

### 2.3 选镜像（这一步别选错）

创建实例的页面里，找到「**镜像**」→ 选「**基础镜像**」→ 然后：

```
框架：PyTorch
版本：2.1.0 或更新的都可以（不要低于 2.0）
Python：3.10 或 3.11
CUDA：12.1
```

**只要 torch 版本对，其他都会自动装。**

### 2.4 开机器

点「**立即创建**」，等 1–2 分钟，状态变成「运行中」就绪。

---

## 3. 传文件

### 3.1 打开 JupyterLab

实例卡片上点「**JupyterLab**」，会新开一个网页。

左边是一棵树（文件列表），右边是工作区。

### 3.2 上传

1. 左边文件树里，双击进 **`/root`** 目录
2. 把本机的 `dataset.zip`、`setup.sh`、`train.sh` **三个文件直接拖进左边文件树**
3. 等上传完（13 MB，几秒钟）

> 拖不进去就用左上角的「↑」上传按钮。

### 3.3 解压训练集

左上角「**+**」→ 选「**Terminal**」，打开一个终端窗口。

在黑框里粘贴这一行，回车：

```bash
cd /root && unzip -o dataset.zip
```

看到 `inflating: dataset/1_ryou/...` 一大串就对了。

**验证一下**：

```bash
ls dataset/1_ryou | head
```

应该能看到 `ryou_bunny_bust.png` 这样的文件名。

---

## 4. 装环境

同一个终端窗口，粘贴这一行，回车：

```bash
cd /root && bash setup.sh
```

**然后去倒杯水。** 这一步 8–15 分钟，它会：

```
1. git clone sd-scripts          约 1 分钟
2. pip install 一堆依赖           约 5 分钟
3. 下底模 6.5 GB                 约 3 分钟
4. 自检 torch / cuda
```

**成功的标志**是最后三行类似这样：

```
torch 2.1.0 | cuda True
diffusers 0.40.0

>>> 环境好了，接着跑 bash /root/train.sh
```

> **如果 git clone 卡住不动**：先按 `Ctrl+C` 停掉，然后执行 `source /etc/network_turbo`（AutoDL 的学术加速），再重跑 `bash setup.sh`。

---

## 5. 开始训练

```bash
cd /root && bash train.sh
```

进度条会从 `0/330` 跑到 `330/330`。

**4090 上大约 1.2 秒一步，全程 8–12 分钟。**

每 3 轮存一次，跑到一半就能看到文件出来：

```
/root/output/ryou_v2_1024-000003.safetensors
/root/output/ryou_v2_1024-000006.safetensors
...
/root/output/ryou_v2_1024.safetensors        ← 最终版
```

**成功的标志**：

```
epoch 15/15
saving checkpoint: /root/output/ryou_v2_1024.safetensors
>>> 下一步：把 /root/output 里的 safetensors 下载回本地
```

---

## 6. 拿结果

1. 回到 JupyterLab 的文件树
2. 进 `/root/output/`
3. **右键每个 `.safetensors` → Download**
4. 下载到本机，比如 `D:\HarnessAI\work\生图环境\output\`

**至少下载 `ryou_v2_1024.safetensors` 这一个**（约 162 MB）。中间版本想对比就一起下。

---

## 7. 释放机器（这一步最重要）

**关机不等于不花钱。**

AutoDL 上「关机」之后，系统盘还在收存储费。要彻底不花钱，必须：

```
控制台 → 容器实例 → 找到这台 → 更多 → 释放
```

**释放前确认三件事**：

- [ ] LoRA 文件已经下载到本机
- [ ] 截图或者抄下了训练日志最后的 loss 数字
- [ ] 没有别的东西还在传

**释放之后不可恢复。** 别手快。

---

## 8. 回到本地

### 8.1 放进 ComfyUI

把下载的 `ryou_v2_1024.safetensors` 复制到：

```
生图环境\ComfyUI_windows_portable-marduk191-v1.0\ComfyUI\models\loras\
```

### 8.2 出图对比

打开工作流 `凉-基础工作流.json`，把 LoraLoader 节点的下拉框换成新的 `ryou_v2_1024.safetensors`，强度 **1.0**。

用同一句提示词、同一个种子，和 v1 的出图放一起看。

**重点看三处**：脸型、眼睛的锐度、头发层次。

## 附一：出错对照表

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `git clone` 一直不动 | GitHub 没走加速 | `source /etc/network_turbo` 后重跑 |
| `wget` 下到一半断了 | 网络抖动 | 重跑同一条命令，`-c` 会接着下 |
| `ModuleNotFoundError: xxx` | 依赖没装全 | `pip install xxx`，然后再跑 train.sh |
| `CUDA out of memory` | 显存被占了 | `nvidia-smi` 看有没有别的进程，重启实例最干净 |
| `找不到 /root/dataset/1_ryou` | 第 3.3 步没做 | `cd /root && unzip -o dataset.zip` |
| 训练跑了很久不动 | 同上，检查进度条 | `nvidia-smi` 看 GPU 利用率 |

---

## 附二：换别的平台怎么办

| 平台 | 差别 |
|---|---|
| **算家云** | 界面不同，流程一样；镜像选 PyTorch 2.x |
| **优云智算** | 有现成 ComfyUI 镜像，但我们用不上；按秒计费 |
| **恒源云** | 最便宜（3090 ¥0.76/时），但是**竞价实例**，可能被中途收回 |
| **蓝耘 / 公有云** | 贵，别用 |

**共通的三条**：

1. 镜像一定选 **PyTorch 2.x + CUDA 12.x**
2. 数据放 `/root` 或平台的数据盘
3. **释放，不是关机**

---

## 附三：这一小时到底在买什么

| 做什么 | 本地 | 云上 |
|---|---|---|
| 1024 分辨率训练 | **跑不了** | 8–12 分钟 |
| 装环境 | 已装好 | 8–15 分钟 |
| 下底模 | 已有 | 3 分钟 |

**你买的是「1024 分辨率」这一个能力**，不是速度。

所以：**别在云上调工作流，别在云上抽卡。** 训完、下载、释放，走人。
